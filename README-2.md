# ÉtuConnect

Application sociale pour élèves.

**Lien :** https://stefi3274.github.io/EtuConnect/

## Fonctionnalités
- Authentification (email ou téléphone)
- Fil d'actualité avec réactions, commentaires, stories
- Profil personnalisable (photo, niveau, talents)
- Messagerie privée + Clubs
- Découvrir avec suggestions intelligentes
- 3 langues : Français, English, Español
